# Supervisor Agent

Dataflix's orchestration layer is a Databricks **Agent Bricks Multi-Agent
Supervisor** (`Dataflix Supervisor`, serving endpoint `mas-de7a56a6-endpoint`).
It's what the chat UI, casting recommender, and compliance-memo generator all
call under the hood.

**This agent is not represented anywhere else in this repo as code.**
Multi-Agent Supervisors are a managed Databricks product configured through
the workspace UI or the `databricks supervisor-agents` CLI directly against
the live endpoint — there's no bundle/YAML definition to check in. This file
is a point-in-time export of its configuration so the design is visible
without needing workspace access.

## Tools

| Tool | Type | What it does |
|---|---|---|
| `engagement` | Genie Space | Watch-hours, completion rate, day-1 retention by region/week, and catalog/cast data (genre, industry, which actors star in which titles). |
| `licensing` | Genie Space | Internal license terms per title/region (type, expiry, renewal cost, exclusivity, rights holder) **and** the real official content certification/rating per title/region (PG-13, U/A 13+, A, TV-MA, etc). |
| `content_signals` | Genie Space | Real vision-FM poster tagging (dominant color tone, composition style, emotional tone) for a 20-title subset, sourced from actual TMDB poster art. |
| `marketing` | Genie Space | Synthetic campaign spend/impressions/CTR/conversion-rate for 3 real thumbnail variant types per title, joined to real face-detection tags. Performance deliberately encodes Netflix's published A/B-testing findings. |
| `documents` | UC function (`dataflix.docs.search_documents`) | Semantic search over real content-ratings/regional-compliance regulatory documents plus Dataflix's own synthetic licensing contracts. |
| `tmdb_search_titles` | UC function | Live TMDB search — catalog lookups beyond the static 130-title Dataflix snapshot. |
| `tmdb_movie_details` | UC function | Real TMDB financials for a specific title: revenue, budget, runtime, genres. |
| `tmdb_trending` | UC function | Currently-trending TMDB movies, for grounding recommendations in real audience demand. |
| `web_search` | UC function (DuckDuckGo) | Last-resort general web search for facts nothing else covers (e.g. streaming availability). Weak on obscure/fictional titles. |
| Trends MCP | External MCP service | Cross-platform trend/demand signal (Google Search, TikTok, Reddit, YouTube, Wikipedia, and more) via a registered Unity Catalog HTTP connection. |

`tmdb_*` and `web_search` are Unity Catalog SQL functions wrapping
`http_request()` against real external APIs (TMDB, DuckDuckGo), governed by
UC HTTP Connections with credentials stored in a Databricks secret scope —
not hardcoded anywhere. Trends MCP is registered the same way, but as an
external MCP Service rather than a UC function.

## Routing logic (summary)

The full instructions are ~20K characters of accumulated, tested behavior;
the highlights:

- **Person/actor/director questions** ("who is X", "tell me about X") skip
  Dataflix's internal tools entirely and go straight to the external chain
  below — internal Genie spaces don't track biography, so checking them
  first just wastes a call. The one exception is a question explicitly about
  that person's relationship to Dataflix's own catalog (e.g. "which Dataflix
  titles has this actor appeared in").
- **External fallback chain**, in order, for anything not in Dataflix's own
  data: `tmdb_search_titles` → (if revenue/budget) `tmdb_movie_details` → (if
  trend/demand) `tmdb_trending` / Trends MCP → (genuine last resort)
  `web_search`. TMDB search is literal, not fuzzy — a single misspelled
  letter can return zero results for a real title, so the agent retries once
  with a corrected spelling or a trimmed name before concluding something
  doesn't exist.
- **Source citation**: every externally-sourced fact in a final answer must
  be labeled (`Source: TMDB`, `Source: Trends MCP`, etc.) — never blended in
  as if it were Dataflix's own data.
- **Tool-call reliability**: UC-function tool calls run on serverless
  compute that can occasionally cold-start past a 90-second timeout. On that
  specific error the agent retries the identical call once rather than
  guessing at a cause — and is explicitly told never to narrate a failure as
  a "permissions issue" or "configuration issue" unless it actually knows
  that to be true.
- **Compound questions** (e.g. "is renewing this license worth it given how
  well it's performing") call every relevant tool and synthesize across
  them, explicitly surfacing tension between sources (e.g. strong completion
  rate but poor cost-per-watch-hour) rather than picking one clean narrative.
- A large block of the instructions is dedicated to real regional compliance
  detail extracted from the indexed regulations — India's IAMAI Code
  penalty framework, IT Rules 2021 grievance/takedown SLAs, EU AVMSD
  jurisdiction, MPA advertising rules, and CBFC dubbed-version certification
  routing — so compliance questions get quantified, regulation-grounded
  answers instead of generic hedging.

## Data governance

External API credentials (TMDB, Trends MCP) are stored in the
`dataflix-mcp` Databricks secret scope and referenced via `secret()` inside
Unity Catalog HTTP Connections — never embedded in function source or
committed to this repo. The Next.js app's own service principal is granted
`USE_CONNECTION`/`EXECUTE` on exactly the objects it needs, nothing broader.
